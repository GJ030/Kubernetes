# Kubernetes

Prácticas de **DevOps**: manifiestos de Kubernetes en YAML, un playbook de Ansible, workflows de GitHub Actions y una API en .NET lista para contenerizar con Docker.

## Contenido

| Ruta | Descripción |
|---|---|
| [`gaelnginx.yaml`](gaelnginx.yaml) | Pod de Kubernetes con el contenedor `nginx`. |
| [`myfirstyaml.yaml`](myfirstyaml.yaml) | Primer Pod definido con un manifiesto YAML. |
| [`actividad7`](actividad7) | `mydeploy.yaml`, un Deployment de Kubernetes. |
| [`verify_apache.yaml`](verify_apache.yaml) | Playbook de Ansible que instala y verifica Apache (`httpd`) en los hosts `webservers`. |
| [`.github/workflows`](.github/workflows) | Workflows de GitHub Actions: demo básica, uso de variables, ejecución de un script de Python y compilación de la API .NET (`CI - Unit Test`). |
| [`.net/ExploringActions`](.net/ExploringActions) | API de ASP.NET Core (`WeatherForecast`) con `dockerfile`, usada para practicar CI/CD. |
| [`python`](python) | Script de práctica `print_n_numbers.py`, usado en el workflow de Python. |

## Tecnologías

Kubernetes, Ansible, YAML, GitHub Actions, Docker, .NET y Python.
